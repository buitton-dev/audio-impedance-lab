# Audio Impedance Lab

ギター、エフェクター出力、オーディオ配線の回路定数を動かし、機材・等価回路・電気的伝達特性の対応を確認できる、ブラウザだけで動く教材です。
https://buitton-dev.github.io/audio-impedance-lab/


## 主な機能

- Pickup DCR/L/自己容量/共振減衰、Volume/Toneの部品値とノブ位置、ケーブル、Amp入力を変更
- Source Rout、ケーブル長と単位長R/L/C、Load Rinを変更
- エフェクター出力のRout、Cout、出力対地抵抗と次段Rinを変更
- 「標準バッファ出力」「小容量Cout」「ハイ出し・ロー受け」の比較
- 低容量・標準・Canare GS-6容量参考のケーブルプリセット
- ケーブルLの増減に連動するコイル記号（大小を示す教材用表示）
- 「ロー出し・ハイ受け」「ハイ出し・ロー受け」「ギター直結」の比較
- 実物のまとまりを点線枠とアイコンで示し、値が連動する等価回路
- 回路図上の数値・R/L/Cシンボルを上下ドラッグして直接変更。タップ／クリックによる数値入力とキーボード操作にも対応
- R・L・CはE24系列を基本に、250/500 kΩポットやケーブル実測値などの用途固有値を加えた離散値で変更
- スライダーは折りたたみ式の詳細設定として利用可能
- 初期値との比較曲線、極端値にも追従するグラフ縦軸の自動調整、スマートフォン表示、ライト／ダーク配色

## 操作方法

数値またはR・L・Cのシンボルを上へドラッグすると増加、下へドラッグすると減少します。タップ／クリックで数値入力、フォーカス後の上下矢印キーで増減、Enter／Spaceで数値入力もできます。PCではShiftを押しながらドラッグすると微調整できます。

| 操作対象 | 変更するもの |
|---|---|
| 通常のR・L・Cシンボル | 対応する部品値 |
| Volume／Toneの抵抗シンボル | ポットの総抵抗値 |
| Volume knob／Tone knobの数値 | ノブ位置 |
| Cable lengthの数値 | ケーブル長 |
| ケーブル内のR・L・Cシンボル | 単位長あたりの定数（回路図には合計値を表示） |

シンボルの操作領域は最小表示時でも短辺約45 pxを確保しています。数値・シンボルの操作領域ではスクロールを抑止し、余白ではページの縦スクロールや回路図の横スクロールができます。「詳細設定」のスライダーも利用できます。

## 設定範囲とグラフ

| 対象 | 設定範囲 | 値の選び方 |
|---|---|---|
| ケーブル以外のR | 1 Ω〜100 MΩ | E24系列＋用途固有値。Grid stopperは0 Ωも可 |
| Pickup L | 1 µH〜100 H | E24系列＋Pickup公称値など |
| ケーブル以外のC | 1 pF〜1,000 µF | E24系列＋用途固有値 |
| ケーブル長（全3モード） | 0.5〜100 m | 0.5 m刻み |
| Volume／Toneノブ位置 | 0〜10 | 通常0.1刻み |

ケーブルの単位長定数の範囲は従来どおり、Rは0〜1 Ω/m、Lは0〜2 µH/m、Cは50〜200 pF/mです。ギターモードではケーブル容量のみを扱います。プリセットの初期値は変更していません。

現実的な部品値を外して共振・減衰の変化を観察できるよう、実験範囲を広げています。これらの範囲は、実部品の入手性や実機としての成立を保証するものではありません。

周波数軸は20 Hz〜20 kHzの対数表示、利得の縦軸は現在値と初期値の両方に合わせて自動調整します。縦軸の目盛りも変化するため、曲線の見た目だけでなくdB値で比較してください。グラフ表示の下限処理は−240 dBです。

## 回路モデル

各モードの教材上の目的と画面構成の判断基準は[教材設計方針](LEARNING_GOALS.md)にまとめています。

### ギター

ピックアップ内部起電力に直列の `Rp + jωLp` を置き、そのホット側に自己容量 `Cp` と共振の減衰をまとめて表す等価抵抗 `Rdamp(eq)` を並列接続しています。そこから先は次の構成です。

- Tone: 可変抵抗とコンデンサの直列枝
- Volume: 上側抵抗と下側抵抗に分割した3端子ポット。ワイパーが出力
- Cable: `長さ × 単位長容量` の対地容量
- Amp: 入力ジャックの `Rin` と、`grid stopper + Cin` の枝

表示する伝達特性は `Vgrid / pickup内部EMF` です。Volume/Toneのノブは10%オーディオテーパー相当で近似しています。`Cin` は真空管単体の端子間容量ではなく、Miller効果を含む実効入力容量として扱います。

`Stratタイプ`とは、Fender Stratocaster系で一般的なシングルコイルPickupと250 kΩのVolume/Toneを想定した呼び方です。この教材では3個のPickupや5ウェイスイッチ全体ではなく、Pickupを1個だけ選択した状態を計算します。

### 接続とケーブル

ケーブル長と単位長定数から合計R/L/Cを求め、`Source Rout + Cable R + jωL` と、`Load Rin || 1/(jωC)` の分圧として計算しています。音声帯域のケーブルを集中定数で近似したもので、長い伝送線路の反射や遅延は扱いません。100 mまでの設定は、このモデル上で合計R/L/Cの影響を調べるための拡張であり、分布定数の伝送線路解析へ切り替わるわけではありません。

回路図のコイル記号のループ数は、ケーブルの合計Lが増えるほど多くなる教材用表示です。実際のケーブル内部が表示どおりに巻かれている、またはループ数からLが直接決まる、という意味ではありません。

### エフェクター出力

エフェクター内部の小信号源から、`Cout → 出力直列Rout → 出力端子 → Cable → 次段Rin`の順に接続し、出力端子から`Rpull-down`を対地に置いています。次段入力での電圧`Vout / 内部信号源`を表示します。

- `Cout`はDCを遮断する出力カップリングコンデンサです。
- `Rout`はCout後に実在する直列出力抵抗として置いています。
- `Rpull-down`は出力端子のDC電位を安定させ、接続時のポップノイズを抑えるための対地抵抗です。
- `Cout`は、概ね`Rout + (Rpull-down || Rin)`と組み合わさって低域ハイパスを作ります。
- 高域側は主に`Rout`とケーブル容量の組み合わせで変化します。

このモードでは`Rout`をCout後の直列抵抗、`Rpull-down`を出力端子の独立した対地抵抗として分けています。現在はCoutとRoutの間に分岐がないため、両者の直列順序を変えても計算結果は同じです。ただし、将来この節点へVolume potを対地接続できるよう、回路図と説明では実装意図どおりの順序を明示しています。「接続とケーブル」モードは一般化したThevenin信号源を扱うため、対地抵抗を別部品として置いていません。

## 初期値の根拠

プリセットは「実製品の公称値」と「説明用の仮定」を区別しています。

- `Stratタイプ（例示）` と `PAFタイプ（例示）` は代表的な範囲から選んだ教材用の値で、特定製品の再現ではありません。
- `Fender ’57/’62` は DCR 5.4 kΩ、インダクタンス 2.1 Hのみメーカー公称値です。自己容量、損失抵抗、ポット、ケーブル、アンプ条件は例示です。
- Pickup自己容量 100 pF、損失抵抗 1 MΩ、アンプ実効入力容量 100 pFは調整可能な初期仮定です。個体・配線・回路で変わります。

## このモデルに含まれないもの

弦・ボディ・ピッキング位置による原信号のスペクトル、複数ピックアップ間の相互作用、ボリュームのtreble bleed、Tone配線方式の違い、エフェクターの能動回路の周波数依存・クリッピング・電源条件、真空管の非線形、パワーアンプ、スピーカー、マイク／室内音響は含みません。そのためグラフは総合的な音色ではなく、線形化した回路と入力負荷の電気的伝達特性です。
